# Code of conduct

Be kind, be specific, assume good intent. Critique code and ideas, never people. No harassment, insults or personal
attacks, in issues, pull requests, discussions or anywhere else this project lives.

Maintainers may edit or remove comments, and block people who do not follow this. To report a problem privately,
use GitHub's "Report content" on the comment, or open a private security advisory if it involves a vulnerability.

This follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/).
