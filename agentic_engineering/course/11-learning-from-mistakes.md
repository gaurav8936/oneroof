# Learning from mistakes

## Agents forget, files do not

An agent that hit a strange error today will hit it again tomorrow unless something tells it otherwise. The fix is
plain: write the lesson down where the next session will find it.

## One fact per note

Keep each note small: the symptom someone would search for, the cause, and the fix. Name the file after the symptom
and the date. Small notes are easy to find, easy to update, and easy to delete when they stop being true.

## Rules belong in one place

When a note becomes a rule, such as "always do this before that", move it into the shared rulebook so every agent
follows it, and leave a pointer behind. A rule kept only in one agent's private memory protects only that agent.

## Read before you act

Notes only help if they are read. Point to the relevant ones from the must-read list and from each handoff, and have
skills check for them before risky steps.

## Skills for this lesson

capture-gotchas writes these notes in a consistent shape. last-call makes sure lessons from a session are saved before
it ends.
