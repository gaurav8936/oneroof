# You steer, agents build

## The shift

When an agent can write a working function in seconds, typing stops being the slow part. What becomes slow, and
valuable, is knowing what to ask for, noticing when the answer is wrong, and deciding what happens next. Your job
moves from producing every line to directing the work and judging it.

## Three jobs that stay with you

First, set direction: pick the problem worth solving and say why. Second, define done: write down how anyone could
check that the work is finished, before it starts. Third, review: read what came back, run it, and accept or reject
it. Agents can help with all three, but the call is yours.

## Why "done" comes first

An agent will always produce something. Without a check written in advance, you end up judging the work by how
confident it sounds. A one-line test, a command that must pass, or a screenshot that must match turns review from an
opinion into a fact.

## Keep the decisions visible

Small choices pile up: a library, a file layout, a name. Ask agents to list the decisions they made and the ones they
need from you. A short list you can scan beats discovering a surprising choice three days later.

## Skills for this lesson

plan-objective turns a goal into steps with a check for each one. write-the-spec helps you define done before any code
is written.
