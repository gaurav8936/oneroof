# Start here

## What this is

This is a short course on agentic engineering: building software with coding agents doing most of the typing, and
you doing most of the deciding. It ships inside One Roof, so every idea here has a matching skill you can run in a
real session. Each lesson takes a few minutes to read or listen to.

## Who it is for

It is for anyone who already uses one coding agent and wants to use several without losing track. You do not need to
know any framework. You need a terminal, a git repository, and at least one agent such as Claude Code, Codex, Kimi or
Gemini.

## How the pieces fit

There are two kinds of material. Lessons explain an idea and why it matters. Skills are instructions an agent follows
to put that idea into practice, like opening a session with a clear picture or closing it with nothing left unsaved.
Each lesson ends by naming the skills that go with it.

## How to use it in One Roof

Open Learn with Command Shift E. Pick a lesson to read it, or press play to hear it. When a lesson points to a skill,
open the skill and choose "Use in a session" to send it to a running agent. To make the skills available to every
agent on your machine, run the sync script in this folder once.

## The order

Read the lessons in order the first time. The first half is about how the work changes. The second half is about the
habits that keep several agents honest: shared memory, the right agent for each job, parallel work without
collisions, evidence, clean session boundaries, safe shipping, and learning from mistakes.
