# strategy/

**Product strategy** for this scope: where the product is going and why (the bets, the principles it is judged by, features by role, the business model, the roadmap and its gates, measures and risks).

- What goes here: strategy documents and their revisions, one file per strategy, dated `YYYYMMDD_<topic>` (owner's .docx or Markdown).
- Not here: an initiative's working plan (`projects/`), a single decision (`decisions/`), a rule that always applies (`standards/`).
