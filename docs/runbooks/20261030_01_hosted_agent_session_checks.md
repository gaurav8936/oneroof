# Start and recover a hosted coding session

**Status:** IN REVIEW · **Date:** 2026-10-30 · **Project:** LAB-AE-OPEN-AGENTS

> **One line:** select a saved hosted connection and specific repository, verify local readiness, then use the native terminal for the continuing conversation.

## Before starting

1. Confirm the installed release actually contains the integration; local commits and test bundles are not an installed release.
2. In Settings → Seats & accounts, save the provider, exact model ID and external credential file reference. Never paste key values into other fields.
3. Verify today's input/output prices and explicit session/shared ceilings. Together/OpenRouter catalogue refresh is available; Fireworks prices require official-page verification.
4. Select the prepared Python/PyYAML, reviewed kit, pinned OpenCode 1.19.5/Goose 1.57.0 and private storage. Keep them and the credential outside the repository the agent edits.

## Operate

Choose OpenCode or Goose, its connection and a specific repo in New session. Launch prepares a private native home and verifies version, guard and reservation headroom off the main thread. Authentication is checked by the first paid request. Wait for native readiness before sending an opening; the holder sends a configured opening only once.

Use the composer/native terminal for follow-ups. Goose's exact radio menu is supported in Needs you. OpenCode approvals stay in its native terminal; Escape rejection is supported. Unknown dialogs remain manual. Timed/repeating hosted schedules are refused in the app and daemon; explicitly selected single-round manual loops are separate.

## Recover

Reopen a still-live holder to preserve the conversation. Native resume after process termination is not implemented: relaunch starts a new conversation and retains its aggregate budget. Save a handoff before ending important work. If prices/runtime settings changed, preparation refreshes the managed phase; it does not reset the aggregate ledger.

For a refusal, check the external key reference, current prices, exact model, pinned executable, installed guard and remaining caps. Never delete a ledger to obtain capacity. Failed/pending reservations remain estimates; consult the provider for final billing.
